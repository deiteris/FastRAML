# raml-codegen

Generate source code from a fastRAML effective-tree document.

```bash
fastraml tree api.raml > api.json
raml-codegen python api.json -o out/
```

The two commands pipe, so nothing needs to touch the disk in between:

```bash
fastraml tree api.raml | raml-codegen python - -o out/
```

## Input

A `fastraml tree` document — JSON, not RAML. This package depends on no parser,
so producing the tree and generating from it can happen on different machines
and at different times. [docs/16 § 11](../../docs/16-graph.md) specifies the
format.

`raml_codegen/tree.py` is the typed declaration of that format, generated by
`python -m fastraml.views.bindings python`. Do not edit it; the parser's gate
fails when it is stale.

## The `python` target

A typed `httpx` client, in the shape
[openapi-python-client](https://github.com/openapi-generators/openapi-python-client)
established, with stdlib dataclasses in place of attrs:

```
out/<package>/
  __init__.py  client.py  errors.py  types.py  security.py  py.typed
  models/      one module per type
  api/         one module per endpoint and method
  pyproject.toml  README.md
```

The generated package depends on `httpx` and nothing else.

```python
from bookstore_api import security
from bookstore_api.api.books import get_books

client = security.OAUTH2.client(base_url='https://acme.books.example.com/v2', token=...)
books = get_books.sync(client=client, limit=10)
```

Each endpoint module exposes four entry points. `sync_detailed` and
`asyncio_detailed` return a `Response[T]` carrying the status code, the raw
content, the parsed body and any mismatches; `sync` and `asyncio` return the
parsed body alone.

### Types

| tree | Python |
|---|---|
| `string`, or with `enum:` | `str`, `Literal['a', 'b']` |
| `integer`, `number` | `int`, `float` |
| `boolean` | `bool` |
| `datetime`, `datetime-only` | `datetime.datetime` |
| `date-only`, `time-only` | `datetime.date`, `datetime.time` |
| `file` | `File` |
| `nil`, `null` | `None` |
| `any` | `Any` |
| `object` with properties | a generated dataclass |
| `object` without | `dict[str, Any]` |
| `array` | `list[T]` |
| `union` | `A \| B` |
| `json` | its `projection` |
| a recursion marker | the type it repeats, by name |

**Models are flat.** `Magazine` is not a subclass of `Publication`: it carries
its supertype's properties and is a class of its own. Where the document states
a `discriminatorValue:`, the module holds it as `DISCRIMINATOR`, which is what
to switch on in place of `isinstance`.

**A union is told apart by what the document says**: a `discriminator:` and its
`discriminatorValue:` first, then a required property no sibling requires, then
whether the value is a list or an object. Where the document distinguishes
nothing, the value is handed back undecoded.

### Names

A type declared by name keeps it. One declared inline is named from the first of
these that exists:

1. `displayName:`
2. where it sits — `POST /orders` gives `PostOrdersBody`, `PostOrders201Response`
3. the property it hangs off — `shipTo:` gives `ShipTo`
4. its array, for inline `items:` — `GetOrders200ResponseItem`
5. its address

Two files may declare one name; the second is disambiguated by its file.

### Security

`security.py` holds one `SchemeSpec` per `securitySchemes:` entry: the header
that carries the credential, and what precedes it. Each module under `api/`
carries a `SCHEMES` tuple naming which of them its operation accepts.

```python
client = security.MACHINE_TOKEN.client(base_url=..., token=...)
```

## When the API drifts from the document

**A payload never raises.** A client that failed on a response mismatch would
stop working the first time the API moved, and would lose the whole body over
one changed property.

| the server | the client | reported in |
|---|---|---|
| adds a property | ignores it | — |
| adds an `enum` value | passes it through | — |
| drops a required property | leaves the attribute `UNSET`, keeps the rest | `Response.mismatches` |
| sends an unreadable value | returns no parsed body, keeps `content` | `Response.mismatches` |
| sends the wrong shape | returns no parsed body, keeps `content` | `Response.mismatches` |
| changes a property's type | passes it through | — |
| answers with an undocumented status | returns `None`, or raises `UnexpectedStatus` when asked | — |

```python
result = get_books.sync_detailed(client=client)
if not result.matched:
    log.warning('the API has moved: %s', '; '.join(str(one) for one in result.mismatches))
```

`UNSET` is falsy, so `if book.isbn:` works without a caller knowing any of this.
The annotation still says `str`: making every property `str | Unset` would price
the normal case for the abnormal one.

Pass `Client(strict=True)` to raise `errors.UnexpectedPayload` instead. It and
`UnexpectedStatus` are both `errors.ClientError`.

## What it does not do

**It does not validate.** A `pattern:`, a `minimum:` or a `maxItems:` reaches
the docstring, not a check. Numeric bounds stay the exact decimal strings the
tree carries and are never divided.

**It states no RAML rule.** Every rule ran before the tree existed. Two
decisions here are client conventions rather than readings of the language:
`sync()` returns the lowest documented `2xx`, and a request body uses the first
declared media type. There are no `4xx` response classes — RAML states 3-digit
codes only.

## Working on it

```bash
uv sync --all-extras --dev
uv run ruff check . && uv run ruff format --check . && uv run mypy raml_codegen/ && uv run pytest -q
```

The suite reads two committed trees, `tests/api.json` and `tests/inline.json`,
so it needs no parser. It compares generation against the golden record in
`tests/golden/`, then runs `ruff`, `mypy --strict` and `compileall` over the
result, imports it, and drives requests through an `httpx.MockTransport`.

```bash
uv run python tests/regenerate_golden.py
```

Refresh the trees from the repository root with
`fastraml tree fixtures/sample/api.raml -w fixtures`. The root's
`tests/unit/test_bindings.py` fails while `tests/api.json` is stale.
