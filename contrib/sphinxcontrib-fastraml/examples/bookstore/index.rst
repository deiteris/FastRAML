Bookstore API
=============

The :raml:api:`books` lets a store keep its catalogue of books, shelves and
deliveries. This site documents version :raml:version:`books`, served at
:raml:base-uri:`books`.

Everything under *Reference* is generated from the RAML specification, so it
cannot drift from it. The guide and the changelog are written by hand, and
link into the reference by name.
